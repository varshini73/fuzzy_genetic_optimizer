About This Project

Academic Abstract

Small-scale local businesses often struggle to determine optimal product pricing due to uncertain market conditions, fluctuating demand, and varying competition. Incorrect pricing leads to profit loss or reduced customer retention. This project presents a Fuzzy-Genetic Micro-Business Pricing Optimizer — an intelligent decision-support system designed to assist local sellers in setting effective product prices.

Technical Architecture
Fuzzy Logic System

Mamdani inference engine with 18+ linguistic rules. Handles uncertainty via membership functions for demand, competition, quality, and season.

Genetic Algorithm

Evolves 8 pricing parameters over 100 generations using tournament selection, uniform crossover, and Gaussian mutation.

Backend

Flask REST API with background threading for long-running optimization jobs. Results cached in session storage.

Frontend

Bootstrap 5 dark theme, Chart.js for bar/line charts, Plotly for interactive 3D scatter and convergence plots.
